Security & compatibility

Keep your bot token private. This static GitHub Pages version has no backend, so browser requests use the token directly. Never hard-code a token or commit one to your repository.

If the browser reports a CORS or network error, use a small authenticated backend hosted separately. GitHub Pages cannot run Node.js server code.
